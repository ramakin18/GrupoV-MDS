# PRODUCT.md

## Users
- Developers maintaining the project
- End users accessing the product and client registration features
- Administrators managing product and client data

## Product Purpose
Educational project for learning Angular 21 with Clean Architecture and SOLID principles.
Features product listing/creation and client registration.

## Brand
Clean, professional, educational. No flashy branding - focus on code quality and clean design.

## Tone
Technical, clear, educational, professional.

## Anti-references
- No emojis as icons
- No glassmorphism for this educational project
- No overly complex animations
- No decorative-only elements

## Register
product

## Strategic Principles
- Clean Code principles
- SOLID architecture
- Accessibility first
- Responsive design
- TypeScript strict mode
